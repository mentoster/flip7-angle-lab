# Flip7 Angle Lab v0.1.13 — Experimental research release

**Samsung Galaxy Z Flip7 (SM-F766B) · Android 13+ · offline inference without ADB**

This release publishes a signed Android APK for investigating continuous
hinge-angle estimation with public Android sensors. It bundles a 120-tree
gradient-boosted model and offers device-local adaptive correction,
real-time magnetometer/gravity/gyro diagnostics, sensor-stream monitoring
and explicit uncertainty labels when a whole-device rotation could be
mistaken for hinge movement.

## APK and model

- **Installable artifact:** `Flip7AngleLab-0.1.13-release.apk`.
- **Package:** `com.mentoster.flip7anglelab`, versionCode 14.
- **Standalone mode:** no root, PC, ADB, cloud inference or log access
  required to run the built-in model. Accuracy in unfamiliar orientations
  and magnetic environments remains experimental.
- **Optional Samsung reference:** exact SensorsHub events require
  developer permission and user consent to read device logs. This is
  only for benchmarking and supervised calibration, not ordinary inference.
- **Data:** raw device recordings and local learned samples are not
  included in the APK download or public Git source.

The release also attaches a machine-readable **aggregate benchmark JSON**
with no private sensor rows. Five SVG charts and the full methodology
are available in the repository:

https://github.com/mentoster/flip7-angle-lab/blob/main/docs/research-methodology.md

## Important limitations

The exact Samsung hinge-angle sensor is privileged. The public
Android hinge posture is coarse. Rotation guards can prevent some
false angle movements but **cannot perfectly distinguish simultaneous
whole-device rotation and slow folding** with the available sensors.
Do not use the displayed angle as a calibrated measuring instrument.

The benchmark numbers are from a single device and recorded
calibration sessions, **not universal precision guarantees**.

## Installation note

This APK is signed with a **dedicated persistent release certificate**,
not the development Android debug key. If the debug edition with the
same package name is installed, Android will reject an in-place upgrade
due to signature mismatch. Export any calibration you want to retain
before uninstalling the debug app; ordinary uninstall removes its
private data. Later public releases should use this same release key.
